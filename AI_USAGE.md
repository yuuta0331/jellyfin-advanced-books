# AI Usage

Jellyfin Advanced Books uses AI-assisted development tools as part of its engineering workflow.

AI tools have been used for tasks such as:

- design and implementation assistance
- code review and defect discovery
- documentation drafting and editing
- test planning and validation support
- release and repository-maintenance assistance

AI output is not accepted solely because it was generated by an AI system. Changes are reviewed against the project requirements and validated with the project's automated checks and tests before they are merged or released.

Project maintainers remain responsible for the code, documentation and releases in this repository.

## Contributions

Contributors may use AI-assisted development tools.

When AI tools materially assist a pull request, disclose that use in the pull request description and briefly state what the tools were used for. The contributor remains responsible for:

- correctness and security
- appropriate testing
- licensing and provenance
- maintainability
- responding to review feedback

AI-assisted contributions are held to the same review and quality requirements as other contributions.
