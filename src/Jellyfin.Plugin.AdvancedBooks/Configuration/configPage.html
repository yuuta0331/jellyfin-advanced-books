Komga compatibility

Books under a matching directory are resolved as independent One-Shots before Jellyfin's default book resolver.
Default: _oneshots. Like Komga, a plain value matches anywhere in the directory path. Prefix with / (for example /_oneshots) to require a directory segment that starts with the value.
Komga models a One-Shot as a one-book series. "Book title" approximates that model in Jellyfin.
Restart Jellyfin and rescan the affected Books library after changing resolver settings.
