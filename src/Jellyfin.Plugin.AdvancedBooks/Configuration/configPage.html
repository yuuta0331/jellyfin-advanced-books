Advanced Reader

When the Jellyfin 12-compatible JavaScript Injector plugin is installed, Advanced Books registers its reader automatically and adds an Advanced Reader button to supported CBZ/ZIP book detail pages. Restart Jellyfin after changing this setting.
Optional. On supported CBZ/ZIP books, Jellyfin's Play/Resume and Start from beginning actions open Advanced Reader instead of the built-in reader. Resume keeps saved progress; Start from beginning opens page 1. Restart Jellyfin after changing this setting.

Komga compatibility

Books under a matching directory are resolved as independent One-Shots before Jellyfin's default book resolver.
Default: _oneshots. Like Komga, a plain value matches anywhere in the directory path. Prefix with / (for example /_oneshots) to require a directory segment that starts with the value.
Komga models a One-Shot as a one-book series. "Book title" approximates that model in Jellyfin.

Direct Komga metadata sync

Reads metadata stored in Komga's database through its API. ComicInfo.xml is not used. Matching is based on the Komga book file URL and Jellyfin Book path.
Recommended. If an API key is configured, it is preferred over Basic authentication.
Used only when no API key is configured.
Optional, one mapping per line. Use this when Komga and Jellyfin see the same files through different container/host paths. The longest matching source prefix wins. No title-based fuzzy matching is used.
You can also run “Sync metadata from Komga” manually from Dashboard → Scheduled Tasks.
Restart Jellyfin and rescan the affected Books library after changing resolver settings.
