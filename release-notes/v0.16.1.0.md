## Highlights

- **Native Jellyfin actions everywhere:** Advanced Reader can replace supported Book actions across details, Home/Library cards, lists, keyboard/remote commands and context menus.
- **Two-way ComicsPlayer progress:** Advanced Reader and Jellyfin's built-in ComicsPlayer share the same per-user page position and played state.
- **Reader launch hotfix:** the standalone Advanced Reader button works again when native action replacement is disabled.
- **More stable Reader UI:** Settings/Help structure, interaction-aware auto-hide and page-position visibility are improved.
- **Natural zoom and pan:** Fit Screen/Width pinch, wheel and toolbar zoom keep the focal page point stable and avoid unreachable black space.
- **Refreshed catalog identity:** the plugin catalog now uses the dedicated purple/blue Advanced Books open-book icon.

## Jellyfin Integration

- Use Jellyfin's normal `UserItemData.PlaybackPositionTicks` store for Advanced Reader progress.
- Preserve Jellyfin Web ComicsPlayer's `pageIndex * 10,000` tick convention.
- Treat ordinary Play/Resume as a server-side resume lookup so stale mounted card/list DOM cannot reset a book to page 1.
- Keep explicit Replay/Start-over as page-1 actions.
- Keep unsupported, inaccessible and non-CBZ/ZIP items on Jellyfin's original action path.
- Restore the dedicated Advanced Reader detail button by routing it through the same direct `openItem` API used by native replacement.
- Expose `supportsItem` alongside `openItem` for a stable compatibility probe.

## Reader UI & Zoom

- Suspend chrome auto-hide while the user is actively pressing, dragging, scrubbing, scrolling controls or using an open Reader panel.
- Keep Settings and Help headers fixed while their bodies scroll independently.
- Add functional mobile Settings-sheet resize/close gestures and keyboard handling.
- Allow the bottom page/range position to be hidden without disabling progress tracking.
- Remove paged pinch preview/commit jumps.
- Clamp pan against the actual rendered page/spread and keep focal zoom anchored in Fit Screen and Fit Width.
- Keep Vertical/Webtoon pinch anchored to the page under the gesture rather than total document height.

## Validation

- Add source guards for the direct Reader launch API.
- Add guards ensuring native generic actions use shared server progress instead of DOM `data-positionticks`.
- Keep the existing reader size, syntax, localization, embedded-resource, package and reproducibility validation.
- Add explicit manual two-way Jellyfin ComicsPlayer <-> Advanced Reader resume coverage.

## Updating

- This release targets Jellyfin Server **12.0.x** / .NET 10.
- Existing reader progress and preferences remain compatible.
- The native Jellyfin action replacement remains **off by default**.
- Restart Jellyfin after updating the plugin.
