## Highlights

- **Reader layout recovery:** restore the original full-width top and bottom Reader chrome on desktop and mobile instead of the floating pill layout introduced during the recent UI work.
- **One zoom model:** toolbar zoom, Ctrl+wheel, double-tap and pinch now update the same Reader-owned zoom state instead of layering separate transforms.
- **Live pinch tracking:** the image point under the previous two-finger midpoint follows the new midpoint on each animation frame.
- **Reliable pan bounds:** paged zoom and one-finger/mouse drag share the same rendered-content clamp so pages cannot be dragged into unreachable black space.
- **Continuous zoom fixes:** Vertical/Webtoon Fit Screen now scales image height with zoom and anchors to the actual touched image when possible.
- **Catalog rollback:** restore the original Advanced Books Catalog artwork that rendered more reliably in Jellyfin's plugin detail surface.

## Reader shell

- Preferences no longer overrides the main Reader top/bottom chrome geometry, background, radius, icon sizing or mobile placement.
- Mobile no longer replaces the original direct top actions with a generated **…** menu.
- Settings and Help retain their independently scrolling panel/sheet UI, but their CSS is isolated from the Reader shell.
- Page-position visibility only controls the numeric page/range presentation and does not introduce an idle floating page pill.
- Existing auto-hide interaction protection remains in place for dragging, scrubbing, focused controls, Settings, Help and Pages.

## Zoom & pan

- Replace the former `installAnchoredZoom` / `applyTransform` layering with one focal zoom controller over `reader.zoom`, `reader.panX` and `reader.panY`.
- Keep one coordinate model for + / − / reset, Ctrl+wheel, double-tap and two-finger pinch.
- During pinch, preserve the content point under the previous midpoint and move it to the new midpoint, so two-finger translation follows the fingers rather than only changing scale.
- Pinch rendering is animation-frame throttled and uses the real Reader transform throughout; there is no separate preview transform to convert on release.
- Paged pan bounds are calculated from the actual rendered image/spread and are enforced during both zoom and subsequent drag.
- Reset pan when zoom returns to 100% or below.

## Vertical / Webtoon

- Fit Screen scales both the continuous canvas width and the image height cap with the Reader zoom.
- Continuous focal zoom uses the actual image under the pointer/fingers when available and falls back to its page slot only for surrounding whitespace.
- Fit Width, Fit Height and Original Size use the same source-to-target focal tracking path.
- Native one-finger scrolling remains available at normal zoom.
- Above 100%, touch drag pans the enlarged continuous canvas when touch gestures are enabled.
- Turning **Touch gestures** off immediately restores native scrolling instead of leaving `touch-action:none` active.

## Preserved v0.17 behavior

- Keep two-way Jellyfin ComicsPlayer / Advanced Reader progress synchronization.
- Keep lifecycle-safe progress persistence on hidden/page-exit paths.
- Keep the standalone Advanced Reader direct-launch API.
- Keep optional native Jellyfin Book action replacement across details, cards, lists, remote commands and context menus.
- Keep played-state interoperability and explicit Replay/Start-over behavior.

## Validation

- Prevent Preferences from reintroducing top/bottom Reader chrome layout overrides.
- Prevent the mobile More replacement from being automatically attached.
- Reject the legacy layered zoom patch and temporary pinch preview scaling.
- Require drag-time pan clamping, source-to-target pinch tracking, touch-input resynchronization and continuous Fit Screen height scaling.
- Keep JavaScript syntax/size, localization, build/test, embedded-resource and reproducible-package validation.

## Updating

- Existing reader preferences and Jellyfin reading progress remain compatible.
- The native Jellyfin action replacement remains optional.
- Restart Jellyfin after updating the plugin.
