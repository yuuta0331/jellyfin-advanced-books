## Highlights

- **Desktop title width fixed:** title and metadata now use the available top-chrome width instead of stopping at the former 32rem / 42vw cap.
- **Pages button restored everywhere:** the grid button now attaches from the Reader's canonical opening event, so it appears for dedicated Reader launches, native Play/Resume replacement, cards/lists/context menus and direct `AdvancedBooksReader.openItem()`.
- **Empty Pages gap removed:** the Pages host collapses while empty, so the top chrome never reserves a phantom button-sized gap before Navigator attachment.
- **Scrubber auto-hide fixed:** pointer-based page scrubbing releases the range input's focus on pointerup/cancel, allowing chrome auto-hide and center-toggle to work again.
- **Keyboard accessibility preserved:** Tab/arrow-key interaction with the range control still keeps keyboard focus because the blur is limited to pointer completion.

## Reader chrome

The v0.16.1.0 visual design remains the reference:

- centered compact desktop bottom pill;
- idle page/range pill plus thin progress rail;
- floating rounded mobile top/bottom chrome;
- mobile **…** More menu for Fullscreen/Help;
- direct Pages and Settings controls.

On desktop, metadata now flexes into the unused space between Close and the right-side controls. The old empty top spacer is removed so it does not consume extra flex gaps.

## Pages navigator

The navigator no longer depends on clicking the dedicated `.advancedBooksReaderButton`. It listens to `advancedbooks:reader-opening`, the same event emitted by all Reader launch paths. This restores the grid button on both desktop and mobile when the Reader is opened through Jellyfin's native action replacement or the public Reader API.

The existing page-grid behavior, thumbnail loading, stale-request cancellation and jump-to-page logic are unchanged.

## Page scrubber

During pointer interaction, Reader chrome still remains visible. When the pointer is released or cancelled, the range input now releases its pointer-acquired focus before restarting the normal auto-hide timer. That prevents the interaction guard from treating the Reader as permanently active after a page jump.

Keyboard-driven range changes do not call `blur()`, so Tab focus and arrow-key page selection remain usable.

## Preserved behavior

- v0.17.1 unified zoom/pan and pinch behavior;
- Vertical/Webtoon Fit Screen and focal zoom fixes;
- lifecycle-safe progress persistence;
- Jellyfin ComicsPlayer / Advanced Reader progress interoperability;
- played-state interoperability;
- native Book action replacement and explicit Replay/Start-over semantics;
- existing Settings/Help/mobile More presentation.

## Validation

CI now checks that:

- desktop metadata has no arbitrary fixed maximum width;
- the obsolete top spacer is not consuming layout space;
- pointer scrub completion releases range focus;
- the keyboard/change path does not blur the slider;
- Pages attaches from `advancedbooks:reader-opening`;
- the old dedicated-button-only Navigator trigger does not return.

## Updating

Existing Reader preferences, reading progress and plugin configuration remain compatible. Restart Jellyfin after installing the update.
